❓ Slide 2: The Problem We Solved

Before MatchMindAi, existing sports prediction tools had major limitations:

❌ Static Historical Data Only
Old tools only look at static past statistics. They ignore today's live pitch reports, weather changes, or team squad updates.
❌ Messy Raw Data Dumps
General AI chatbots return messy raw URL links (e.g. Source [1]...) instead of simple, crisp 1-line answers.
❌ Lack of Match Simulation
Fans cannot simulate thousands of ball-by-ball match scenarios to see highest expected scores and score distribution ranges.

🚀 Slide 3: Our Solution (MatchMindAi)

We created a Multi-Agent AI Platform that solves all three problems at once:

  • 10,000-Run Monte Carlo Simulation Engine: Simulates 10,000 ball-by-ball matches per click incorporating team ratings, venue pitch profiles, and stadium dew factors.
  • 1-Line Direct Factual Answers: Instantly answers player team queries, Orange Cap winners, Purple Cap winners, and Champions for any year (2008–2026).
  • Real-Time Internet Web Intelligence: Scrapes live Google News RSS feeds to incorporate today's pitch and weather news.
  • High-Energy 4D Cyber UI: Dark cyberpunk theme, live stadium video header, and interactive 4D depth particle cursor radar.

🏗️ Slide 5: System Architecture & Data Flow

Here is how data flows through MatchMindAi when a user asks a question or predicts a match:

1. User Prompt / Selection ➔ User types a query or selects two teams.
2. Smart Intent Router ➔ Checks if query is a greeting, identity question, IPL history lookup, or match prediction.
3. Parallel Sub-Agents Triggered:
    • Web Scraper Agent: Scrapes live Google News for pitch & weather news.
    • Monte Carlo Agent: Simulates 10,000 ball-by-ball matches.
    • RandomForest ML Agent: Queries trained machine learning model.
4. Ensemble Blend ➔ Combines 55% Monte Carlo + 45% ML to calculate final win probability.
5. Streamlit Cyber UI ➔ Renders win gauges, score graphs, and crisp markdown commentary.
SLIDE 6 OF 10

📊 Slide 6: Machine Learning & Simulation Details

  • RandomForest ML Classifier: Trained on historical IPL datasets using scikit-learn. Pre-compiled weights are saved as .pkl binary files inside models/.
  • Stochastic Monte Carlo Math: Calculates run probabilities per ball based on team rating (CSK 88, MI 87, RCB 85) and venue dew factor (Wankhede 0.12, Chinnaswamy 0.15).
  • Interactive Plotly Graphs: Displays score distribution histograms showing the expected run ranges for both teams across 10,000 simulated matches.

⚡ Slide 7: Challenges Faced & Solutions

🔴 Challenge 1: GitHub 100 MB Limit Error

Problem: git push was blocked because dataset/IPL.csv was 104.93 MB.

✅ Solution:

Removed IPL.csv from git history because model weights were already compiled into .pkl binary files inside models/.

🔴 Challenge 2: Streamlit Cloud Import & Path Errors

Problem: Relative file paths like "models/match_predictor.pkl" crashed on Streamlit Cloud Linux servers.

✅ Solution:

Used Python's os.path.abspath to dynamically find exact absolute folder paths on Linux.

🔴 Challenge 3: Natural Language Phrasing Variations

Problem: Typing "who wins 2018 ipl" (present tense) bypassed the router which only checked for "who won" (past tense).

✅ Solution:

Expanded regex keywords to catch all phrasing variations ("who wins", "wins", "win", "won", "winner").
